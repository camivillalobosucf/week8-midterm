# BabyTrack 👶

A simple web app that helps parents log feedings, diaper changes, and sleep — all in one place. Built as a midterm project to practice modern front-end development with React.

## Planned Features

- **Feeding Tracker** — Log breast, bottle, or solid feedings with time and notes
- **Diaper Tracker** — Record wet, dirty, or mixed diaper changes quickly
- **Sleep Tracker** — Track naps and nighttime sleep with start and end times
- **Edit & Delete Entries** — Update or remove any logged entry at any time
- **Daily Summary Dashboard** — View a quick overview of your baby's day at a glance

## Tech Stack

- React
- Vite
- CSS
- localStorage
- GitHub
- Netlify / Vercel

## Setup

```bash
# Clone the repository
git clone <your-repo-url>
cd BabyTrack

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`.

This project is currently in the scaffolding phase. The landing page and project structure are in place, but the full tracking functionality (forms, data persistence, dashboard) will be implemented during the midterm build in Week 8.
